taskdial

常驻置顶的任务轮盘 —— 一次只喂一片时间，年轮记录每片长了多少。
这里是它的本地 HTTP API：人看 /insights，agent 看 /skills。

只读（窗口关着也能用）

  • GET/insights暂停报告网页
  • GET/healthok / version / phase / uptime
  • GET/skills给 agent 的能力清单（JSON；markdown 版）
  • GET/control/state当前完整状态

控制（依赖 app 窗口活着，不在时 503）

  • POST/control/slices加一片 {name, lenMin}
  • PATCH/control/slices/:id改名 / 改片长
  • DELETE/control/slices/:id删一片
  • POST/control/pause暂停 {reason?}
  • POST/control/resume继续

试一下

curl http://127.0.0.1:7717/control/state
curl -X POST http://127.0.0.1:7717/control/slices -d '{"name":"写文档","lenMin":25}'
curl -X POST http://127.0.0.1:7717/control/pause -d '{"reason":"会议"}'

默认只绑 127.0.0.1:7717，没有 token。绑定地址和端口在 app 配置目录的 server.json 里改；放开绑定意味着同网段任何人都能改状态，想清楚再动。
